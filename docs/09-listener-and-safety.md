# 09. Слушатель и безопасность

## Роль ИИ
Системный промпт слушателя собирается из настроек (`app/prompts.py:listener_system`):
- честно ИИ, не притворяется человеком;
- роль (слушатель, собеседник, интервьюер) задаёт максимальную длину реплики (14, 30, 35 слов);
- тон, юмор, форма обращения («Sie/du», «Вы/ты»), реакция на грусть берутся из настроек;
- язык ответа совпадает с языком человека;
- запреты: советы, оценки, диагнозы, сравнения, выдуманные факты.

Как часто слушатель отвечает, решает `_reply_due` (`api.py`): интервьюер каждый раз, собеседник и слушатель по настройке частоты (слушатель при «редко» отвечает только после длинного рассказа).

## Что ИИ делает с рассказами
| Задача | Правило |
|---|---|
| Теги | только разрешённые ключи вопроса, только `true/false`, чувствительные только при согласии |
| События | только явно названные, без выдуманных дат, имён и мест |
| Главы | только факты из транскриптов, голос рассказчика, неясное помечается `[?]`, подтверждение человеком |
| Комикс | только факты из главы |
| Итог сессии | благодарность и краткий пересказ без новых фактов |

## Кризисный протокол
1. `safety.detect_crisis` проверяет каждую реплику человека (русский, немецкий, английский).
2. При срабатывании: запись сохраняется с флагом, **не** попадает в книгу, события и итоги; интервью не продолжается; человеку возвращается фиксированный текст `CRISIS_TEXT` (поддержка, просьба обратиться к близкому, экстренный номер 112, Telefonseelsorge).
3. Кнопки: «Продолжить запись» или «Сделать паузу на сегодня».
4. В системном промпте слушателя есть та же инструкция на случай, если фраза не распознана детектором.

Ограничения: детектор простой, он не поймает все формулировки и не заменяет человека. Расширьте список, проверьте тексты и номера для вашей страны и согласуйте протокол со специалистом по психическому здоровью до запуска.

## Эмоциональная безопасность и зависимость
- Тяжёлые темы только с согласием, можно закрыть и вернуться.
- Слушатель не должен звучать как «лучший друг». Приложение предлагает делиться главами с семьёй.
- Не добавляйте механик удержания (серии дней, чувство вины за пропуск, «я скучал»).
