# 06. План развития

## Фаза 0 (первые дни в Claude Code)
1. `make setup`, `make test`, `npm run build`: убедиться, что всё собирается.
2. Docker: `make up`, пройти сценарий из `07-testing.md`.
3. Подключить ключ Anthropic и STT, проверить качество на 10-15 реальных голосах.
4. Подобрать порог громкости детектора пауз (`VOICE_THRESHOLD` в `useRecorder.js`) на разных телефонах.

## Фаза 1: запуск закрытой беты
- Перевод банка вопросов, сценария знакомства и интерфейса на немецкий (`/translate-questions`), выбор языка `APP_LANG`.
- Экран согласий и политика конфиденциальности (см. `04-privacy-dsgvo.md`).
- Подтверждение почты, сброс пароля, лимит попыток входа.
- Кусочная загрузка аудио во время записи (не терять длинные рассказы при обрыве связи).
- Фоновая обработка (очередь) вместо синхронной.
- Интерфейс правки транскриптов (API уже есть).
- Режим «помощник-родственник»: ребёнок настраивает и запускает, родитель только говорит.
- Тесты фронтенда (Vitest + Testing Library) и e2e (Playwright) для основного сценария.
- Postgres и миграции.

## Фаза 2: ценность и «подарок»
- **Комикс с картинками:** генерация иллюстраций в едином стиле (персонажи фиксируются по описанию, без реальных лиц и фото без согласия), редактор панелей.
- **Печать книги:** вёрстка PDF под print-on-demand, обложка, фото в главах, заказ и оплата (Stripe).
- **Дорога жизни как интерактивная страница** по ссылке для семьи (с паролем и сроком жизни ссылки).
- **Фото и документы:** режим `by_photo`: человек показывает фото, вопросы строятся от него.
- **Аудиоархив:** нарезка лучших фрагментов, подарочный плеер.
- **Серверный TTS** с приятным немецким голосом (Piper локально или облако ЕС).
- Голосовое знакомство (мастер настроек голосом), напоминания по расписанию (email, push).
- Доверенный контакт: уведомление по согласию при признаках тяжёлого состояния, по заранее оговорённым правилам.

## Фаза 3: рост
- Семейный аккаунт: несколько рассказчиков и общая книга семьи.
- Реалтайм-режим как необязательная опция.
- Улучшение распознавания диалектов (дообучение, подсказки по именам и местам).
- Партнёрства: дома престарелых, соцслужбы, библиотеки, подарочные сервисы.
- Оценка качества: метрики (доля пропусков, длина сессий, возвраты), опрос удовлетворённости пожилых пользователей.

## Идеи на потом
- Режим интервью для близких: внуки задают свои вопросы дедушке, приложение вплетает их в сценарий.
- Поддержка двух языков в одной записи (например, немецкий и русский у переселенцев).
- Тематические проекты: «рецепты семьи», «история дома», «письмо внукам».
