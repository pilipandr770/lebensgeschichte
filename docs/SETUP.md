# SETUP: как запустить в Claude Code

Это пошаговая инструкция. Всё, что нужно заполнить, отмечено **ЗАПОЛНИТЬ**.

## 0. Что понадобится
- Python 3.11+ (проект проверен на 3.12), Node.js 20+, `make`
- Docker (для деплоя и для проверки образов)
- Ключ **Anthropic API** (для настоящего ИИ). Без ключа всё работает в mock-режиме, этого достаточно, чтобы пройти интерфейс
- Для распознавания речи: либо свой сервер с Whisper (faster-whisper), либо облачный API (см. шаг 3)

## 1. Распаковать и открыть
```bash
unzip lebensgeschichte.zip && cd lebensgeschichte
claude          # запуск Claude Code в корне проекта, он прочитает CLAUDE.md
```
Полезные слэш-команды лежат в `.claude/commands/`: `/test`, `/translate-questions`, `/deploy-check`, `/add-question`.

## 2. Установка и первый запуск без ключей (mock-режим)
```bash
make setup                 # venv, зависимости бэкенда и фронтенда, копирует .env.example в .env
make test                  # 25 тестов бэкенда, должны быть зелёными
make validate              # проверка банка вопросов (102 вопроса)
make dev-backend           # терминал 1: API на http://localhost:8000
make dev-frontend          # терминал 2: интерфейс на http://localhost:5173
```
Откройте http://localhost:5173, создайте аккаунт, пройдите знакомство и настройку, нажмите «Рассказать». В mock-режиме можно вводить текст вместо голоса (в настройке канала выберите «писать» или «по-разному»).

Демо-данные: `make seed`, затем вход `demo@example.com` / `demo12345`.

## 3. Заполнить .env
Откройте `.env` (шаблон `.env.example` содержит комментарии к каждому полю).

| Поле | Что сделать | Обязательно |
|---|---|---|
| `SECRET_KEY` | **ЗАПОЛНИТЬ**: `python3 -c "import secrets; print(secrets.token_urlsafe(48))"` | да |
| `ANTHROPIC_API_KEY` | **ЗАПОЛНИТЬ**: ключ из консоли Anthropic | для настоящего ИИ |
| `ANTHROPIC_MODEL` | проверить актуальное имя модели в документации Anthropic | нет (есть значение по умолчанию) |
| `STT_PROVIDER` | выбрать `faster_whisper` (свой сервер) или `openai_compatible` (облако) | для настоящей речи |
| `STT_LANGUAGE` | `de` для немецкого, `ru` для русского, пусто для автоопределения | нет |
| `STT_API_KEY`, `STT_BASE_URL`, `STT_API_MODEL` | **ЗАПОЛНИТЬ**, если выбран `openai_compatible` | условно |
| `WHISPER_MODEL` и связанные | для `faster_whisper`; на CPU возьмите модель поменьше (`small`, `medium`) | условно |
| `REGISTRATION_OPEN` | на закрытой бете поставить `false` | нет |
| `CRISIS_TEXT` | проверить номера экстренных служб и телефона доверия для вашего региона | рекомендуется |

### Вариант STT A: локальный Whisper (максимум приватности)
1. В `.env`: `STT_PROVIDER=faster_whisper`.
2. Локально: `pip install -r src/backend/requirements-optional.txt` (нужен `ffmpeg`).
3. В Docker: `INSTALL_OPTIONAL=all` в `.env`, затем `docker compose up --build`.
4. Для GPU нужен образ с CUDA и проброс GPU; на CPU используйте `WHISPER_MODEL=small` или `medium` и учитывайте задержку.

### Вариант STT B: облачный API
`STT_PROVIDER=openai_compatible`, укажите `STT_API_KEY`. Подходит любой сервис с эндпоинтом `/audio/transcriptions` (формат OpenAI). Для DSGVO нужен договор об обработке данных (AVV/DPA) и ЕС-регион: см. `04-privacy-dsgvo.md`.

## 4. Проверка настоящего ИИ и речи
1. Поставьте ключ и провайдер STT, перезапустите бэкенд (`/health` покажет `llm` и `stt`).
2. Запишите 2-3 ответа голосом (микрофон работает на `localhost` и на HTTPS; на обычном HTTP по IP не работает).
3. Проверьте вкладки «Дорога жизни» (кнопка «Собрать события») и «Книга» (кнопка «Собрать главы»).
4. Прочитайте `07-testing.md`: там план ручной проверки и тест распознавания на реальных голосах пожилых людей.

## 5. Docker
```bash
cp .env.example .env     # заполнить
make up                  # http://localhost:8080
```
Данные лежат в `./data` (база и аудио). Это нужно бэкапить.

## 6. Деплой
См. `05-deployment.md` и обязательно `04-privacy-dsgvo.md` до приёма реальных пользователей.

## Частые проблемы
- **Микрофон не включается:** нужен HTTPS или localhost, плюс разрешение в браузере.
- **`pdf_unavailable` при скачивании PDF:** не установлен WeasyPrint (в Docker ставится по умолчанию). Можно скачать HTML и распечатать в PDF из браузера.
- **Озвучка звучит по-роботному или не на том языке:** используется голос браузера. Серверный TTS в плане развития (`06-roadmap.md`).
- **Транскрипт плохой:** сначала проверьте `STT_LANGUAGE`, затем размер модели, затем качество микрофона. Диалекты нужно тестировать отдельно.
