# 05. Деплой

## Минимальный вариант (бета, до ~10 пользователей)
1. VPS в ЕС (например, Hetzner Cloud CX22 и выше), Ubuntu LTS, Docker и docker compose.
2. Домен и **HTTPS обязателен** (микрофон в браузере работает только по HTTPS). Проще всего поставить перед `frontend` обратный прокси Caddy или Traefik с автоматическими сертификатами Let's Encrypt.
3. `git clone`, `cp .env.example .env`, заполнить (`SECRET_KEY`, `ANTHROPIC_API_KEY`, STT), `REGISTRATION_OPEN=false` для закрытой беты.
4. `docker compose up --build -d`. Данные в `./data`.
5. Бэкап `./data` (cron + шифрование + копия в другое хранилище ЕС), проверка восстановления.

Пример Caddyfile (если Caddy стоит на хосте и проксирует на порт 8080):
```
lebensgeschichte.example.de {
  reverse_proxy localhost:8080
  request_body { max_size 60MB }
}
```

## Whisper на сервере
- **CPU-сервер:** `WHISPER_MODEL=small` или `medium`, задержка в несколько секунд на минуту речи; подходит для беты. Проверьте качество на реальных голосах.
- **GPU-сервер (ЕС):** модель `large-v3-turbo` даёт лучшее качество. Нужен образ с CUDA, проброс GPU в compose (`deploy.resources.reservations.devices`) и `WHISPER_DEVICE=cuda`. Либо вынесите STT в отдельный сервис и подключайте как `openai_compatible` по внутреннему URL.
- Сборка с faster-whisper: `INSTALL_OPTIONAL=all` в `.env`.

## Чек-лист перед открытием для людей
- [ ] HTTPS, домен, редирект с HTTP
- [ ] `SECRET_KEY` случайный и длинный, `.env` не в git
- [ ] `REGISTRATION_OPEN=false`, пользователи заводятся вручную или по приглашению
- [ ] Бэкапы и проверка восстановления
- [ ] Лимит попыток входа и сброс пароля (см. roadmap)
- [ ] Мониторинг: `/health`, место на диске, ошибки в логах (без персональных данных)
- [ ] Политика конфиденциальности, согласия, Impressum, DPA (см. `04-privacy-dsgvo.md`)
- [ ] Проверка кризисных текстов и номеров
- [ ] Ограничение расходов на API (лимиты в консоли провайдеров)

## Масштабирование
- **База:** при росте заменить SQLite на Postgres (слой `app/db.py` небольшой, SQL простой; добавить миграции, например Alembic).
- **Воркеры:** сейчас gunicorn с 1 воркером и 4 потоками (ограничение SQLite). С Postgres можно несколько воркеров.
- **Фоновые задачи:** распознавание и генерация глав сейчас выполняются синхронно в запросе. Для нагрузки вынести в очередь (RQ или Celery + Redis).
- **Хранилище аудио:** при росте перейти на объектное хранилище в ЕС с шифрованием на стороне сервера.
