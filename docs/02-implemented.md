## Функции

### Знакомство и правила поведения
- 7 шагов-знакомства: ИИ честно представляется, объясняет цель, правила (человек главный), приватность. *Зачем:* доверие и согласие до первого вопроса.
- Мастер настроек (23 вопроса): роль (слушатель, собеседник, интервьюер), частота реплик, пауза, тон, юмор, реакция на грусть, табу-темы, уточнения, проверка текста, канал (голос, текст), скорость речи, длина сессии, напоминания, порядок, фото, формат результата, стиль книги, участие семьи, доверенный контакт, завершение, что поднимает настроение. *Зачем:* приложение подстраивается под человека.
- Настройки меняются в любой момент (вкладка «Настройки»).

### Разговор
- Одна большая кнопка «Рассказать», остановка по паузе, кнопка «Закончить», «Рассказать ещё», «Дальше», «Пропустить», «Закончить на сегодня».
- Озвучка ответов и вопросов браузерным синтезатором речи. Текстовый режим для тех, кто хочет писать.
- Реплики слушателя генерирует Claude по системному промпту из настроек: короткие, без советов, без выдумок, честно ИИ.
- Итог сессии: тёплое резюме без новых фактов (по настройке завершения).

### Банк вопросов с ветвлением (102 вопроса)
- Условия показа, приоритеты, вопросы-«ворота» для тяжёлых тем, режимы порядка, подстановка имени партнёра, мостики после тяжёлых вопросов, предложение паузы после двух пропусков.
- Теги извлекаются из рассказов ИИ (с фильтром: только разрешённые ключи, только булевы значения, чувствительные только при согласии).

### Результаты
- **Дорога жизни:** события из рассказов (название, год, место, люди), подтверждение, правка, удаление. Дубликаты отсекаются.
- **Книга:** главы по темам от первого лица «в словах рассказчика» или «чуть литературнее». Редактирование, подтверждение (подтверждённые главы не перезаписываются), экспорт Markdown, HTML, PDF (если установлен WeasyPrint).
- **Комикс:** раскадровка (сцены, описание кадра, подпись). **Картинки не генерируются**, это следующий этап.
- Правка транскриптов через API (`PATCH /api/recordings/<id>`), интерфейс для неё в планах.

### Безопасность и приватность
- Детектор кризисных фраз (русский, немецкий, английский): фиксированный спокойный ответ с экстренными контактами, интервью не продолжается, запись не попадает в книгу и итоги.
- Выгрузка всех данных (zip: транскрипты, события, главы, аудио) и полное удаление аккаунта (`DELETE /api/me`).
- Изоляция пользователей (покрыто тестом), пароли хешируются, токены подписаны и имеют срок жизни.
- Ограничение размера загрузки, опция не хранить аудио (`STORE_AUDIO=false`).

### Инфраструктура
- Docker (backend gunicorn + frontend nginx), `docker-compose.yml`, `.env.example` с комментариями, Makefile, скрипты `tools/`, файлы для Claude Code (`CLAUDE.md`, `.claude/commands`).

## Известные ограничения MVP
- Запись целиком отправляется после остановки (кусочная загрузка во время записи в планах). При обрыве связи на длинной записи она теряется.
- Банк вопросов и интерфейс на русском (черновик). Немецкая версия в плане (`/translate-questions`).
- SQLite и один воркер. Для нескольких пользователей одновременно и продакшена стоит перейти на Postgres.
- Нет подтверждения почты, сброса пароля, лимита попыток входа, платёжного модуля (Stripe), печати книги.
- Озвучка браузерная (качество зависит от устройства).
- Фото и документы как точка входа в рассказ (режим `by_photo`) описаны, но не реализованы.
- Доверенный контакт сохраняется в настройках, но уведомления ему пока не отправляются.
