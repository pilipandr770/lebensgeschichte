# Lebensgeschichte

**Голосовое приложение для создания автобиографии.** Человек рассказывает свою жизнь, ИИ слушает и поддерживает, а из рассказов собираются **книга**, **раскадровка комикса** и **«дорога жизни»** с событиями. Для людей старшего возраста и в подарок семье. Рынок: немецкоязычный (DSGVO, ЕС).

**Цель:** поднять настроение и сохранить историю, превратив рассказ в то, чем можно гордиться и что приятно показать близким.

## Что внутри
| Часть | Что делает |
|---|---|
| Знакомство (7 шагов) | ИИ честно представляется, объясняет цель и правила |
| Мастер настроек (23 вопроса) | Человек выбирает, как с ним говорить: роль, паузы, тон, табу, формат результата |
| Банк вопросов (102, 16 тем) | Ветвление по жизни человека: нет детей, не спрашиваем о детях; тяжёлые темы только с согласием |
| Разговор | Одна кнопка «Рассказать», остановка по паузе, короткие реплики слушателя, озвучка |
| Дорога жизни | События из рассказов, подтверждение и правка |
| Книга | Главы в словах рассказчика, правка, экспорт (md, html, pdf) |
| Комикс | Раскадровка (картинки в следующей версии) |
| Приватность | Выгрузка и удаление данных, чувствительные темы по согласию, кризисный протокол |

## Быстрый старт
```bash
make setup      # зависимости, .env из шаблона
make test       # 25 тестов бэкенда (без ключей)
make dev-backend    # терминал 1
make dev-frontend   # терминал 2 → http://localhost:5173
```
Без ключей приложение работает в mock-режиме (заглушки ИИ и распознавания). Подробно: **[docs/SETUP.md](docs/SETUP.md)**.

## Структура
```
.env.example            шаблон настроек (ЗАПОЛНИТЬ)
CLAUDE.md               контекст проекта для Claude Code
docker-compose.yml      backend + frontend (nginx)
Makefile                setup, test, validate, dev-*, up, seed
docs/                   документация
tools/                  validate_questions.py, seed_demo.py
.claude/commands/       /test, /translate-questions, /deploy-check, /add-question
src/backend/            Flask API, банк вопросов, тесты
src/frontend/           React + Vite
```

## Статус
Готов **прототип (MVP-скелет)**: бэкенд протестирован в mock-режиме (25 тестов), банк вопросов валидируется. **Не проверялись** (в среде сборки не было сети и ключей): сборка фронтенда, Docker-образы, настоящие Anthropic API, Whisper и PDF-экспорт. Рекомендуемый первый шаг в Claude Code: `make setup && make test && cd src/frontend && npm run build`, затем сценарий из [docs/07-testing.md](docs/07-testing.md).

## Важно перед приёмом реальных людей
Это очень личные данные пожилых людей. Пройдите [docs/04-privacy-dsgvo.md](docs/04-privacy-dsgvo.md), проверьте кризисные тексты и проведите тест распознавания речи и юзабилити (docs/07).
