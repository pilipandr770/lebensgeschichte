# Frontend (React + Vite)

- Точка входа `src/main.jsx`, состояния приложения в `src/App.jsx` (intro, wizard, app с вкладками).
- `src/useRecorder.js`: запись голоса, автоостановка по паузе (порог VOICE_THRESHOLD подбирать на реальных устройствах).
- `src/components/Talk.jsx`: основной экран «Рассказать» (пошаговый режим, ответ озвучивается браузерным TTS).
- Интерфейс для пожилых: крупный шрифт, большие кнопки, один вопрос на экран, никаких скрытых меню. Не усложнять.
- `npm run dev` (прокси на бэкенд :8000), `npm run build`.
- Тестов пока нет, это задача из `docs/06-roadmap.md` (Vitest + Testing Library).
